
# 🌍 World Happiness Analysis and Prediction

## 📌 Project Overview
An end-to-end Data Science and Machine Learning project using the World Happiness Report 2024 dataset.

The project explores happiness patterns across countries and builds a Machine Learning model to predict happiness scores.

## 🎯 Objectives
- Analyze global happiness data.
- Identify the happiest and least happy countries.
- Explore relationships between happiness and social and economic factors.
- Build and evaluate a predictive Machine Learning model.

## 🛠️ Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Joblib

## 🤖 Machine Learning
**Algorithm:** Random Forest Regressor

**Target:** Ladder score

**Input features:**
- Log GDP per capita
- Social support
- Healthy life expectancy
- Freedom to make life choices
- Generosity
- Perceptions of corruption

## 📊 Model Evaluation
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score: Approximately 0.86 on the test set

## 📈 Visualizations
- Happiness score comparisons
- Social support and happiness
- GDP and happiness
- Correlation heatmap
- Actual vs predicted scores
- Feature importance

## 📁 Project Files
- `World_Happiness_Final_Data_Science_Project.ipynb` – Complete notebook
- `happiness_prediction_model.pkl` – Trained ML model

## 🏁 Conclusion
This project combines data analysis, visualization, and Machine Learning to explore global happiness patterns and predict happiness scores using selected factors.
